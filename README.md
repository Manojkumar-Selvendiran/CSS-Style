# Student Registration Form

A simple Student Registration Form built using HTML and CSS.

## Features

* Enter student name
* Enter email address
* Enter password
* Select gender
* Choose skills (HTML, CSS, JavaScript)
* Select date of birth
* Register button
* Display sample student records in a table

## Technologies Used

* HTML5
* CSS3

## Project Structure

student-registration-form/

├── index.html

├── style.css

## How to Run

1. Download or clone the project.
2. Open the project folder.
3. Double-click `index.html` or open it in a web browser.

## Learning Objectives

This project helps beginners learn:

* HTML forms
* Input fields
* Radio buttons
* Checkboxes
* Tables
* Basic CSS styling
* Form layout and design

## Note

The student table contains dummy data for demonstration purposes only. The form does not store data because no JavaScript or backend functionality is included.
